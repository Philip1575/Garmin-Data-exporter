A guided setup for historical importing, daily downloads, and on-demand AI reviews. No coding required.

Start in five steps

  1. Extract the entire ZIP. Open the extracted starter-kit folder.
  2. Double-click Setup.cmd. Review the source and README before running an unsigned download.
  3. Choose your preferences. Folder, sync time, display units, and historical start: this year by default, a custom date, or ALL. Folders are created for you.
  4. Log into Garmin privately. Type your password in the local prompt; enter MFA if requested.
  5. Import your history. Allow an hour or longer if needed. Keep the setup window open.
Your PC does the downloading. It needs to be awake, online, and signed in. Missed daily runs can catch up later. The kit does not wake your PC or send data to an AI service.
