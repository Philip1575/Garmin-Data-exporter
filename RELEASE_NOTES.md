# Public source release — Windows pilot v0.2

Prepared October 21, 2026 from the source-only starter kit.

- Runnable Windows installer and Python tools, installer integrity manifest, local help, and 23 mocked offline tests.
- Source is shared under its existing MIT license. Third-party packages retain their own licenses and are installed separately.
- Added public overview, workflow explanation, synthetic example, and a source-repository ignore file.
- Re-ran all 23 offline tests successfully on October 21, 2026. No real Garmin login, data download or scheduled-task change was performed for this release.
- No installed configuration, real activity/recovery data, credentials, token caches, logs, shortcuts, virtual environments or personal filesystem paths are included.
- Fresh-computer installation, Garmin login/MFA, dependency downloads, and scheduled execution remain unverified. This is an experimental pilot, not a production-validated application.

For installation, use GitHub’s Code → Download ZIP, extract the whole archive and read README.md before running Setup.cmd.
